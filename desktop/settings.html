Keep PC awake

Stops Windows from sleeping so your phone can reach the hub anytime. Screen still turns off. Default keeps the laptop awake only while charging (so battery isn't drained). Note: closing the lid still sleeps unless you set Windows' lid-close action to "Do nothing".
